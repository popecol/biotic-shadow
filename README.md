# Biotic shadow

This repository contains the R code and data associated with the results presented in the manuscript *"The biotic shadow: Quantifying the limits of fundamental niche reconstruction under strong interspecific interactions"* by Katarzyna Markowska and Lechowsław Kuczyński.

The study was supported by the National Science Centre, Poland (grant no. 2018/29/B/NZ8/00066) and the Poznań Supercomputing and Networking Centre (grant no. pl0090).

## Included data

- `data.RData` contains the values of the performance metrics used to evaluate fundamental niche reconstruction.

- `GAMM_models.RData` contains the Generalized Additive Mixed Models (GAMMs) fitted to the performance metrics.

Both files can be loaded in the `5_figures.R` script to generate the figures used in the manuscript.
